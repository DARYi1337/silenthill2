# Stillwater — первый концепт

Играбельный технический концепт low-poly психологического хоррора от третьего лица. Первый эпизод — небольшая заброшенная станция техобслуживания: герой исследует её, находит предохранитель, запускает электрический щит и открывает выход. После включения питания знакомый коридор меняется.

Сейчас используются процедурные модели из примитивов Ursina; это намеренный greybox, не финальные игровые ассеты.

## Требования

- Windows 10/11 x64
- Python 3.12+ (проект проверяется на Python 3.14)
- Поддерживаемый OpenGL-драйвер

## Запуск

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m src.stillwater
```

Если установлен Python 3.12 или 3.13, замените `-3.14` на соответствующую версию. В Windows можно также создать окружение командой `python -m venv .venv`.

## Управление

- `WASD` — ходьба относительно камеры
- `Shift` — бег
- мышь — вращение камеры; курсор захватывается при запуске
- `E` — взаимодействие
- `Tab` — открыть/закрыть записку
- `Esc` — пауза и возврат в игру
- `F3` — показать диагностические значения
- `F5` — переключать графический профиль Clean / Retro / VHS

## Проверки

```powershell
.\.venv\Scripts\python.exe -m pytest
.\.venv\Scripts\ruff.exe check src tests
```
