# Fogbound

Учебная атмосферная 3D-игра на Python: короткий психологический хоррор (10–15 минут), вдохновлённый ощущением неизвестности в Silent Hill 2, но с оригинальными героями и историей.

## Концепция
Ночью автомобиль героини глохнет у заброшенного города. Сквозь туман виден одинокий фонарь. Игрок исследует улицу и доступное здание, находит предмет для продвижения и приходит к открытой, тревожной концовке. Основной источник страха — звук, свет, туман и недосказанность; боевой системы нет.

## Стек
- Python 3.11 (рекомендуемая стартовая версия)
- Ursina (поверх Panda3D)
- VS Code + OpenAI Codex
- Blender для подготовки моделей, Git для истории изменений

## Быстрый старт (Windows PowerShell)
```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install ursina
python main.py
```
> `main.py` появится в ходе TASK-0.3. До этого последняя команда не сработает — это ожидаемо. После первой проверки зафиксировать зависимости в `requirements.txt`.
