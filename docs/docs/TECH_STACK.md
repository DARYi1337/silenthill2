# TECH_STACK — Fogbound
Версия: 0.1

## Базовые технологии
| Область | Выбор | Почему |
|---|---|---|
| Язык | Python 3.11 | Понятный учебный стек |
| 3D | Ursina / Panda3D | Быстрый старт и доступ к 3D-сцене |
| IDE/ИИ | VS Code + Codex | Поэтапная реализация с ревью |
| Контроль версий | Git | Откат рабочих версий |
| Модели | Blender | Создание/адаптация low-poly ассетов |
| Звук | Ursina Audio | Достаточно для MVP |
| Тесты | unittest + ручные проверки | Не добавлять лишних зависимостей |

## Форматы
Использовать форматы, реально поддерживаемые выбранным загрузчиком Ursina/Panda3D. Для моделей сначала проверить импорт одного тестового ассета; GLB/GLTF может требовать отдельного плагина/конвертации. Для звука использовать проверенные WAV/OGG. Текстуры PNG/JPG.

## Эффекты
1. Базовый fog средствами Panda3D/Ursina (проверить на тестовой сцене).
2. Простое освещение, имитация фонарика.
3. Только после профилирования — лёгкая постобработка VHS/PSX; отключаемая настройкой.

## Среда
Windows + PowerShell; виртуальное окружение `.venv`; зависимости фиксировать после проверки установки. Не добавлять сетевые сервисы, БД, сложный физический движок или генеративные библиотеки.

## Риски
- Совместимость конкретной версии Ursina и Python — проверить установкой.
- Туман, тени и постобработка могут вести себя по-разному на интегрированной графике.
- Готовые анимации/модели потребуют согласования скелета и форматов.
- Лицензии ассетов и звуков проверять перед включением.

## Решение по умолчанию
Сначала вертикальный срез с кубами, одной улицей и одним взаимодействием. Оптимизировать только по измерениям FPS, не по догадкам.
