# AGENTS.md — инструкции для Codex

Ты работаешь над **Fogbound**, учебным 3D-хоррором на Python и Ursina. Цель — законченная, лёгкая демка на 10–15 минут. Пользователь изучает разработку игр, поэтому решения должны быть простыми и объяснимыми.

## Источники истины
1. `docs/GAME_DESIGN.md` — игровой опыт и границы MVP.
2. `docs/ARCHITECTURE.md` — структура и обязанности систем.
3. `docs/TASKS.md` — текущая задача, критерии приёмки.
4. `docs/TECH_STACK.md` — технологии и ограничения.
При противоречиях сначала спроси пользователя, а не меняй концепцию самостоятельно.

## Процесс для каждой задачи
1. Прочитай релевантные документы и текущий код.
2. Назови ID задачи и предложи короткий план, перечисли файлы для изменения.
3. Реализуй **только одну** задачу с минимальными изменениями.
4. Запусти доступные тесты/проверки. Если GUI нельзя проверить в среде, прямо скажи об этом и дай ручные шаги.
5. Отчитайся: что сделано, какие файлы изменены, что проверено, что осталось непроверенным.
6. Предложи Git-коммит; не выполняй опасные операции с Git и не начинай следующую задачу без подтверждения.

## Инженерные правила
- Python 3.11, Ursina, одна игровая сцена. Не менять стек без согласования.
- Не строить собственный движок, ECS, DI-контейнер, плагинную систему или сложный EventBus без доказанной необходимости.
- Разделять player, camera, world, interaction, events, rendering, audio, UI по ответственностям.
- Не создавать пустые модули и абстракции «на будущее».
- Не смешивать прогресс сюжета с рендерингом и UI.
- Сначала примитивы, затем ассеты; производительность важнее эффектов.
- Писать читаемый код с понятными именами, небольшими функциями и короткими комментариями к нетривиальным местам.
- Не скрывать ошибки, не выдавать непроверенное за проверенное.
- Не использовать материалы, персонажей, музыку или модели Silent Hill без разрешения.

## Готовность изменения
Программа стартует; текущие механики не сломаны; критерии TASK выполнены; README/документы обновлены при изменении интерфейса или структуры. Если тестировать запуск невозможно, явно перечисли ограничения.

## Формат ответа Codex
**Задача:** TASK-X.Y
**План:** 2–5 шагов
**Изменения:** файлы и назначение
**Проверка:** команды и фактический результат
**Ручная проверка:** что сделать в окне игры
**Риски / вопросы:** только существенное
